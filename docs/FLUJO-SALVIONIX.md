# Flujo comercial de Salvionix

Este CRM organiza el seguimiento de consultas y servicios. Los mensajes y
las visitas se coordinan manualmente; el CRM no envía mensajes ni crea citas.

1. **Nueva consulta:** registra el contacto y crea una oportunidad con el
   nombre del servicio solicitado. Una empresa es opcional para hogares.
2. **Contactado:** registra las conversaciones y crea una tarea para el
   próximo contacto o para coordinar una evaluación.
3. **Evaluación del espacio:** anota el tipo de espacio, su dirección,
   tamaño y necesidades. Si se conoce, registra la fecha y hora de la visita.
4. **Propuesta enviada:** registra el importe de la propuesta y anota cuándo
   y por qué medio se envió. La fecha estimada de cierre es comercial y es
   independiente de la fecha de visita. El importe admite actualmente solo
   unidades enteras, sin centavos.
5. **Seguimiento de propuesta:** crea una tarea para consultar la respuesta y
   registra las aclaraciones acordadas.
6. **Servicio contratado:** mueve aquí la oportunidad cuando el cliente
   acepte la propuesta. Debe tener al menos un contacto asociado. El CRM crea
   una tarea de seguimiento para el primer contacto, con fecha inmediata; puedes
   reprogramarla. Coordina la visita y registra su realización. La tarea se
   crea una sola vez por oportunidad, incluso si se cambia de etapa después.
7. **No concretado:** úsala si la propuesta se rechaza o no continúa. Anota el
   motivo. **Aplazado** sirve para las oportunidades que se retomarán después.

La lista de necesidades permite seleccionar una o varias: virus y bacterias,
superficies en contacto con alimentos, moho y hongos, alérgenos, olores,
aire acondicionado y ductos, telas y tapizados u otra necesidad.

El panel de importes suma las oportunidades abiertas sin asignarles una
probabilidad de cierre; estos importes no son ingresos confirmados.
